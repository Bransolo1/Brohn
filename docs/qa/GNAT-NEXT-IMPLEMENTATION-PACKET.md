## Smallest complete seventh profile

Add a named, versioned, original Brohn Go/No-Go procedure using original text exemplars. Freeze target/context and positive/negative category roles, signal/noise quotas, practice/test membership, deadline rounds, ordering/sampling, feedback/interval policy and scoring recipe. No arbitrary shortened variant is implied.

Use dedicated compiler, browser state machine, server replay and scorer modules, following [SC-IAT's isolation](SCIAT-WINDOW-CORE-ACCEPTANCE.md). Do not relax generic IAT correction, RT timeout or correct-key requirements. A valid `correct_rejection` has no response key or response latency, but requires completed visible onset-to-deadline evidence. A missed Go stimulus is a `miss`; an eligible key yields a `hit` or `false_alarm`. Withholding is neither missing data nor a zero/deadline-valued RT.

Retain raw keydown/up, held/repeat/early/late/untrusted classifications, exact clock/page identity, display geometry and interruption evidence. Freeze the exactly-at-deadline rule explicitly. Hidden tabs and page restart cannot silently complete or resume timed trials.

Author in the task editor, rehearse through a separately marked sample/preview release using the same compiler and renderer, publish, complete the actual participant task, inspect the automatic report, export/import complete evidence, summarize declared people/visits, then reopen after restart. The existing material thumbnail preview explicitly does not rehearse a timed procedure.

## Source gates before activation

The current [official manual](https://www.millisecond.com/library/v7/gnat/gnat/gnat/gnatdemo.manual) still gives 750/600 ms in its procedure/parameter sections and 700/550 ms in summary labels. It describes a demonstration, not a reliability-optimized protocol. Its exact-boundary rate adjustment is .005/.995. These facts do not establish a universal default or vendor-equivalent implementation.

The [original author paper](https://banaji.sites.fas.harvard.edu/research/publications/articles/2001_Nosek_SC.pdf) has now been retrieved and its relevant scanned pages reviewed. The lead adopted the explicitly named [Brohn single-target procedure](../methods/GNAT-BROHN-PROCEDURE.md): 384 trials, declared context, two separate 750/600 ms rounds, one-pass practice, exact Go/No-Go quotas and timing, half-open response acceptance, and `.005/.995` endpoint correction. The paper's `0.35/n` correction and its own Table 1/prose deadline discrepancy are recorded separately. This closes the procedure-selection gate; implementation, independent replay/arithmetic and the full researcher/participant journey remain activation gates. It does not establish original/vendor equivalence. Preserve raw and corrected rates, source-specific support and separate deadline results.

## Ownership and acceptance

Independent owners can build (1) domain/compiler/scorer and arithmetic fixtures, (2) browser key-state engine and independent replay fixtures, and (3) connected researcher/import/cohort QA. The integration lead owns shared hooks and the activation gate.

Required evidence: 8/10 hits and 2/10 false alarms give `d' = 1.6832424671458286`, criterion zero within floating-point tolerance; reversed rates reverse sensitivity. Test exact 0/1 correction, absent signal/noise, incomplete cells, practice exclusion and separate deadline support. Exercise real withholding, boundary/late/held keys, interrupted/reloaded trials, full native CSV-to-import agreement, repeated-person cohort policy, portable reuse and restart. Freeze all six existing profile snapshots unchanged. Software arithmetic/replay acceptance does not establish physical timing, population reliability or material validity.
