# Optional MaxDiff item illustrations

20 September 2026. Accepted bounded material-authoring slice for enabled
object-case MaxDiff exercises. This does not complete the 50-capability register.

Researchers can attach, describe, preview, replace and remove a PNG for each
saved MaxDiff item from Tasks. The editor pins the exact study revision and
complete exercise, including its offered sets. Image controls require saving
or cancelling an open exercise draft first. Invalid bytes, missing descriptions
and stale authority retain a recoverable local editor. Ordinary exercise edits
preserve item illustrations; removal deletes only the optional image field.

Items without illustrations retain their original canonical fields. Images
change the source hash deliberately, while labels, offered order, requiredness
and the paired-choice method retain their existing meanings. Canonical choices
contain no transport URLs. Exact original PNG bytes and authored descriptions
survive publication, clone, template and cross-workspace ZIP import. An older
release continues to authorize only its original material.

The participant prepares unique question and choice illustrations before any
new question visit or choice onset. An image failure exposes an untimed retry
in the same allocation. Each native best/worst group receives a separate prepared
image with the same item-specific description, preserving mixed text/image
order. Partial pairs, same-item exclusion, optional clear-and-skip, draft reload,
lost receipts and questionnaire branch/review retain their existing behavior.
Resumed choices retain active-segment timing without claiming uninterrupted RT.

The existing PNG authoring limits apply: 5 MiB, 4096 pixels per side, 8 million
pixels per image and nonempty descriptions up to 2000 UTF-8 bytes. Question and
choice illustrations share at most 64 million unique decoded pixels; their
unique compressed bytes plus passive stimulus media share 512 MiB. Task-image
and welcome preparation retain separate existing bounds. Both R and browser
preflight enforce this engineering profile. No new image format or AOI route
is introduced.
