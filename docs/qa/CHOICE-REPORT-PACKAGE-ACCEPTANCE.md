## Scope and source boundaries

The profile adds complete saved MaxDiff findings to the established report
flow. Native questionnaires, imported choice summaries and packed saved cohorts
retain their distinct evidence. Choice counts and utility sections include every
exercise by default, including saved not-requested and unavailable model states.
Figures and 50-row HTML alternatives can be focused without trimming complete
designs, exposures, model parameters, probabilities, timing or imported rows.

An explicit mixed-source admission profile requires every present task/choice
component's exact preparation, even when figures are hidden. Task display 0.2
admits the new mixed source; historical task display 0.1 and earlier report
profiles retain their strict original contracts. Paired views from a task-bearing
packed source use its exact task display, never whichever prerequisite finishes
first. Original references and current reader/source checks remain separate from
the original producer's identity.

Original scientific jobs run before the export boundary. Choice preparation
checks saved support and result shapes without fitting utilities or replaying
choice journals. Native task preparation retains the existing separately
identified display audit; it does not replace saved scores. Assembly and saved
opening do not perform either scientific scoring or delivery-journal replay.
No task–liking or choice–liking estimator is introduced.

Exported task reports also gain plain labels and explanations for 19 registered
metrics across all seven profiles. Administration values, saved individual
summaries and equal-person cohort means retain their distinct meanings; a mean
of individual medians or standard deviations is not a pooled statistic.
Canonical keys, units, support and nulls remain unchanged in evidence. The
source-bound label map and resolver check this display-only scope; detailed
on-screen task views are not claimed to have been relabeled.

## Retained failures and corrections

- The first synthetic resumed-page source omitted a required equipment check.
  The receiver correctly refused it; a corrected fresh fixture passed.
- An early pure validator incorrectly required probabilities for unanswered
  design sets. It now follows the actual producer's answered-set representation
  and checks exact order, support and normalization.
- Independent review found seven malformed results admitted by that draft:
  incorrect parameter types/semantics, missing design coverage and inconsistent
  probability support. All seven are now refused by the frozen implementation.
- An early guard harness tried to alter a terminal run outcome; the database
  correctly refused it. Current project faults and terminal immutability are
  tested separately. Another fixture's read-only file attribute initially
  blocked corruption injection. The final owned copy distinguishes live native
  write protection from post-release checksum refusal.
- A display-label review found that replacing any matching table cell could
  change an identifier or reason that happened to equal a metric key. The
  correction labels only the metric-name column; independent and portable
  checks preserve the other cells exactly.
- The first connected main journey compared distribution companions by their
  figure-section filename. Removing preceding figures legitimately moved
  section 005 to 003 while preserving the original source and exact bytes. That
  harness failure is retained. The corrected fresh browser initial phase passes;
  independent final download and cold-restart checks also pass. No product
  fix was needed for this comparator failure.

These failures remain in external evidence. No source guard was weakened to
make a test pass. Any further integration/browser failures must be recorded
with their own source-specific receipts; no broader acceptance is inferred.

## Limits and continuation

The new mixed native witness uses choice reaction time. It does not newly
qualify all seven task profiles combined with choice; the prior seven-profile
task checkpoint remains separately scoped. Historical RT 1.0 still lacks an
original producer/worker fixture. This adapter does not establish conjoint,
additional choice estimators, physical timing or model/construct validity.

Local current-reader/source gates and native child lifetime are tested. Original
hosted actor expiry was not newly exercised for choice. Temporary test-clock
reclaim is not real elapsed lease-expiry or identity-provider qualification.
The database immutability test does not implement a post-collection withdrawal
interface. Saved offline copies cannot be revoked retroactively.

Task and choice material definitions/hashes are complete; their image bytes and
context panels remain unsupported. Optional image inclusion remains limited to
the qualified gaze profile. Raw/original bundles, larger workloads, remaining
physiological/media adapters, source-open latency and
scoped post-collection restrictions remain work. All 50 capabilities and
17 packages remain active, including BWP04/BWP10/BWP13/BWP14/BWP15/BWP17.
