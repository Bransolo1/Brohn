## Reproduction and deployment boundary

Prepare the verified official tools with `scripts/prepare-hosted-tooling.py`, install the repository's browser-test dependencies and native R/Python configuration, then run from the checkout:

```powershell
node tests/researcher-hosted-profile.mjs ../../work/test-runs/brohn-hosted-browser-YYYYMMDD-NN
```

The destination must be new. The harness owns loopback ports 3911–3917. The vendor lock pins Caddy 2.11.4, oauth2-proxy 7.15.4, Keycloak 26.7.4 and Temurin 25.0.4.1+1; the tooling receipt verifies archive and executable identities. The local TLS CA is not installed into operating-system trust. Only the test browser accepts its fixture certificate. No real participants, account credentials or public deployment are required.
