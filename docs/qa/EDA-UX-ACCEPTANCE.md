# Saved EDA reports: researcher experience

28 September 2026. **The main connected researcher journey has passed, including history and cold restart.** The large-recording flow recovered its display but correctly refused complete export at the package byte bound; it is not an export-recovery success. Exact release source hashes and phase receipts belong in [EDA-REPORT-PACKAGE-SOURCE.json](EDA-REPORT-PACKAGE-SOURCE.json).

The existing Prepare report flow separates event-related and continuous conductance. Defaults include every saved cell, including unavailable cells: phasic conductance for events, and tonic plus phasic conductance for continuous recordings. Candidate-marker pages and numerical-table pages are independent. Representative figure points are labelled as reduced display evidence; complete saved processed rows remain in the package.

For continuous sources, **Choose specific views → Original recording windows** is available before successful preparation. **Change display window** opens original bounds; **Apply display window** changes only the draft. The researcher must explicitly choose Prepare report to create the new request. Reset and Cancel remain available, and earlier failed attempts remain in history. Editing a view does not rerun the method or change whole-segment measures.

Metadata alone does not imply an available waveform, marker count or prepared figure. Unavailable rows stay visible without editable bounds. Figure selectors require exact prepared evidence. A required EDA parent that is not selected retains its original whole window; to edit that parent's window, the researcher must first add the exact saved parent as a selected source. Its figures may then be hidden without dropping its numerical evidence.
