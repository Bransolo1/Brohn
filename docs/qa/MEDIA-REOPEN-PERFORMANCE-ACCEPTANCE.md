## Remaining work and limits

The sampled media result/status regions are initially empty for roughly
3–4 seconds, then show the incorrect instruction that the cursor changed during
programmatic restoration. No useful verification message was sampled before
the result appeared. Generic Shiny busy state changes are recorded separately;
they do not explain this wait. A narrow follow-up should paint accurate opening
status first and distinguish controlled restoration from an actual user edit,
with stale-ticket fencing and unchanged source guards.

This fixture uses a small synthetic video/audio recording and a genuine saved
review corpus. It establishes neither physical synchronization, external sensor
alignment, scientific validity, maximum file/catalog scalability nor field
hardware behavior. Export handlers and immutable artifacts remain unchanged.
