## Source and scope

`tests/researcher-vision-explorer.mjs` and
`tests/fixtures/researcher-vision-explorer.R` use an isolated copy of
`oka/work/brohn-vision-saved-01/workspace`. The original workspace and reference
images remain unchanged outside the repository. That source contains three
actual pinned-model reports and immutable indexes, separately qualified by
[the saved reference record](VIDEO-GEOMETRY-SAVED-REFERENCE.md).

Each report contains four frames made from official static reference imagery.
The cases cover face, pose and hands with original PTS beginning at 2 seconds.
They establish software/source agreement. They are not natural-motion,
population-accuracy, emotion, attention, calibrated-gaze or hardware evidence.
The journey reuses the existing genuine model outputs; it does not rerun
inference or establish fresh model accuracy.

The browser uses the real application, data-library navigation, saved report
entry point and supervised recorded-frame jobs. Independent original JSONL
reads preserve numeric token strings. The harness compares all rendered native
coordinates, exact original frame JSON, complete/range CSV values and metadata,
and delivered PNG pixels against an independent decode of the original source.
It also exercises cancel/retry, state-only/empty views, stale resource links,
report reopen, desktop/narrow layouts and keyboard access.

Meaningful UI paging covers all 478 saved face points, beyond the first 100
visible native-landmark rows. These four-frame reports cannot prove frame-page
navigation or browser behavior beyond the compact 2,000-frame preview. Those
remain separate from this acceptance; worker paging and resource-limit tests
must not be relabelled as connected browser evidence.

## Reproducing the inspection continuation

With the repository's prepared Node, R, Python and native-publication runtimes,
run from the repository root:

```text
node tests/researcher-vision-explorer.mjs ../../work/test-runs/brohn-vision-browser-20260924-03 C:/Users/User/Documents/Codex/2026-09-20/oka/work/brohn-vision-saved-01 --reuse-fixture --finish-inspection ../../work/test-runs/brohn-vision-browser-20260924-03/browser-1790215987687
```

This mode verifies the known post-browser failure, retained assertions/scans,
downloads, original sources and final saved records without launching a browser,
server, model or job. It preserves the original failure file. A normal new run
instead copies the reference workspace into a fresh fixture, serves the real
application on its explicit port, and writes a normal result only after both
browser traversal and final inspection pass. Evidence stays outside the public
repository; the test source and this scoped record are versioned.
