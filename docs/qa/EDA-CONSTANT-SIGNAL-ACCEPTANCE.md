## Findings corrected during development

- Artifact writing now requires a real integer source candidate count and an
  explicit true flatline witness; Python equality alone accepted `False == 0`.
  Downstream validation already refused malformed support; the earlier boundary
  now rejects it too.
- New report-version saves no longer cancel themselves when the form observer
  compares the new 0.2 request with an old 0.1 history profile.
- New history follows the same pinned explicit-distribution prerequisites as
  earlier EDA history, rather than selecting current preparation implicitly.
- Constant coordinate-capacity refusals block ineffective unchanged retries and
  stale Resume events without disabling legitimate source removal/replacement.
- Saved standalone reads verify the original successful producer instead of
  requiring it to have today's code identity. New executions still pin code.
- Manual phone review caught unreadable column compression despite a clean
  automated accessibility scan. The direct review now provides a readable,
  labelled keyboard-scroll table. Large finite raw levels use compact summary
  notation while complete evidence values remain unchanged.
- Report assembly reuses already validated models only within one render and
  rechecks their sealed file bytes. The complete analysis hash is computed once
  per evidence validation rather than once for every cell. No scientific method,
  authority rule, complete-data requirement or worker limit was relaxed.

## Retained test limitations and failures

The source corpus's final assertion initially required every historical job to
have succeeded. Its copied history intentionally contained an old cancelled job.
All preceding source assertions passed. An independent read-only final check
verified that the seven new jobs succeeded on attempt one and all historical
states were unchanged. The original failed receipt and corrected qualification
are both retained; no scientific job was repeated to hide the failure.

Earlier component harnesses assumed one sample rate's row count for every source,
expected result files that had not been retained, or dropped HTML head/styles
when wrapping a component. Their failed receipts remain separate from corrected
checks. They are not reported as application defects or native qualifications.

The synthetic negative-zero saved-feature transport probe is distinct from the
qualified native CSV path, which canonicalizes its published mean before review.
The former is not evidence of an end-to-end native failure. Failed probe harnesses
(temporary-upload policy and incorrect observation field names) remain retained.

The original six-source worker reached its 300-second limit; peak memory and
scratch usage remained below their caps. The unbounded direct diagnostic was used
only to locate redundant validation and serialization, not as a worker pass.
The corrected native workload now passes without increasing its limits; larger
or concurrent workloads remain unqualified. An earlier tampering test copied a
read-only object, so its write failed before the intended mutation; the corrected
test changes permissions only on its disposable copy. An initial byte-comparison
assumption omitted expected implementation metadata changes; conservation checks
now distinguish those explicit identities from scientific values and payloads.

Two integrated cold starts failed the acquisition manager's fixed three-second
readiness wait. Separately starting the exact owned manager enabled the history
check; that workaround does not qualify integrated startup. The later bounded
readiness fix passed 27 focused checks, 74 full supervisor/recording checks and
22 acquisition-state checks; see [startup evidence](RUNTIME-STARTUP-READINESS.md).

separate from actual product findings.
