## Common acceptance for every profile

A researcher selects the outcome and sees only the setup decisions necessary for that outcome: source identity, physical quantity/unit, acquisition or input roles, control/baseline, timing, named recipe and support requirement. Save those decisions in the protocol or analysis revision. Offer a plain-language explanation of what a result measures. A renamed generic score cannot substitute for an unimplemented method.

Every result must retain original source hashes and clock identity, complete selected observations, excluded observations with reasons, transformations and their order, unit conversions, algorithm/package/version, parameters, study/run/participant/session/exposure identities, and support denominators. Missing, rejected, censored, not presented and legitimate zero are distinct. Filters, differences, averaging and joins must not bridge resets, participants, conditions or unsupported gaps. A repeated trial is not a new participant. Reference and replay origins remain visible after export/reopen.

Each family needs a usable default plot plus exact-value inspection and a complete download. Show units, time reference, baseline/control, support and exclusions next to the plot. Preserve spikes and discontinuities when reducing display data; do not run scientific analysis on a plot preview. Test the plotted values against an independent oracle and exported source, including nonzero clock origins, missing spans, clipping, one-point/empty windows, repeated identities and narrow screens. Existing [signal previews](../methods/SIGNAL-PREVIEW.md) and [neural plots](../methods/NEURAL-PLOTS.md) provide reusable pieces, not automatic coverage of every endpoint.

Live readiness is four independent states:

1. **Connected:** the named transport/source identity is present. A running recorder process is insufficient.
2. **Receiving:** selected channels have fresh incoming samples, observed cadence, gap/reset/nonfinite counts and last-receive age.
3. **Recording:** acknowledged committed sample/chunk counts and write failures, independently of receiving counts. A stopped sample stream can coexist with an open file.
4. **Quality for this measurement:** a named criterion and version, source unit/roles, analysis window, minimum support, threshold/rationale and observed value. When evidence or a supported criterion is absent, show unknown and the missing item. Raw preview is still useful.

Channel names alone never establish gaze coordinates, ECG leads, respiration polarity, electrode contact, calibration or physiological validity. A preview selected from16 retained samples is a bounded arrival preview, not a qualified frequency spectrum or beat detector.

The additional register entries remain explicit:

- `gaze.naturalistic`: dynamic coordinate transforms, independently reviewed video/object AOIs and timing-aware replay before dynamic dwell claims.
- `neural.advanced`: connectivity/source localisation/decoding each require distinct models, spatial metadata, leakage/confound controls and independent or held-out validation. PSD/ERP availability does not enable them.
- `cardiorespiratory.coupling`: require synchronized ECG/respiration clocks and valid overlapping support; RSA/coherence need named methods and reference cases. Correlation across unrelated source clocks is invalid.

Multimodal models need explicit outcome/design/participant unit and measurement-specific inclusion; avoid counting repeated sensor samples as people. Clock correction provenance and source identity must survive every display/export.
