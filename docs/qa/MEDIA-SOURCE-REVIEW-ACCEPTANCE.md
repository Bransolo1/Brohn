## Explicit remaining scope

The current saved-media chooser returns the latest 40 records for one audio
window. It does not yet label that limit or provide paging/search across older
positions. All saved records remain retained; do not infer complete historical
navigation from this small fixture. A later UI slice should add a visible limit
and total, then pagination or search. The generic result introduction also says
"The frame below" when the subsequent, correctly displayed warning states that
no frame is supported; this copy refinement is deferred without changing data.

This acceptance does not establish continuous audiovisual playback, external
sensor synchronization, physical timing accuracy, camera qualification, face
inference or new acoustic-method validity. Source permissions, native publication
and byte preservation are software properties checked separately from those
scientific and hardware claims.
