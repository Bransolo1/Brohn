## Limits and continuation

The supported profile is `complete-findings/0.1`, rendered from saved gaze,
questionnaire and paired results. Unsupported selected parents, scientific
collections or schemas receive a reason; existing exports remain available.
Display rounding is disclosed; full numerical JSON/CSV retains saved values.
Aliases preserve links and leave free text verbatim, so they are not anonymity.

This profile excludes raw recordings and original byte-evidence bundles.
Supported PNG/JPEG inclusion requires verified bytes and matching geometry;
unsupported orientation is refused. Offline copies cannot be revoked by later
in-app access changes. Larger profiles, other report adapters, public sharing,
post-collection restrictions, older-backup enforcement, transport review of
other download callbacks, wider installation and
manual assistive-technology/human studies remain open. Device accuracy and
scientific construct validity are not established by presenting saved findings.
