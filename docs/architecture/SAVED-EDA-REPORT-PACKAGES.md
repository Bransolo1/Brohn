## Researcher experience

Select saved EDA and liking findings in the established **Prepare report** flow.
Brohn saves the choices, prepares any missing views and assembles one report.
The default event figure shows phasic conductance with the saved method windows;
continuous figures show tonic and phasic conductance. All applicable saved cells
are included initially. Unavailable cells retain a reason, rather than becoming
zero-valued charts.

Before preparation, **Change contents** can open bounded original continuous
segment windows, including after a default-view limit refusal. This does not
require a prepared plot or read complete sample streams. Applying a new window
changes the draft. An explicit new intent can supersede the old current
head; the original failed or successful revision, request and evidence remain
immutable and linked from the new intent.
Figure-specific selectors still require exact prepared evidence.

After preparation, **Change contents** can select saved events or segments,
choose cleaned/tonic/phasic components, select numerical or candidate-marker
pages, and hide figure sections. These choices affect the illustrated material,
not the complete included numerical evidence.

A continuous figure may use a smaller source-time window. Its exact decimal
bounds are saved independently of the figure choices. Apply changes that window;
Reset restores the original whole-segment view; Cancel preserves the previous
choice. Hiding a figure does not silently reset its window. A changed window
requires new display preparation; a component/page-only edit reuses the same
preparation. Neither action reruns EDA decomposition or event detection.

Event baseline, response, latency and recovery settings belong to the original
scientific method. Report preparation cannot change them. Whole-segment summary
measures remain whole-segment measures when a continuous figure is focused.

The report keeps the existing progress, cancellation, retry and historical
download flow. An oversized request explains which resource exceeded its limit
and what can change. Reducing figures can address a figure limit; it cannot
repair oversized complete evidence. A retry retains the same scientific source
and exact saved choices. It must not display an earlier attempt's diagnosis as
the current error.

## Saved evidence and interpretation

The supported original recipes are continuous `eda-neurokit-highpass/1.0`,
event `eda-event-highpass/1.0` and event `eda-event-cvxeda-defaults/1.0`.
Each source must have a successful exact original producer and supported
study/design binding. Method parameters, baselines, masks, event timing,
exclusions, detector support, nonresponse and missingness remain as saved.

A supported nonresponse can have magnitude zero and null responder amplitude.
Incomplete support is not a nonresponse. Unobserved onset or recovery is not
invented. Continuous candidate peaks have no implied stimulus attribution.
Related EDA and explicit liking retain their original denominators and original
identity mapping; putting figures beside one another creates no new association
estimate or emotion interpretation.

Complete original analysis, features and processed sample/candidate streams are
included for selected EDA and required related EDA parents. Figure pages and
smaller windows never crop those complete streams. HTML numerical alternatives
describe the displayed representative points and candidate pages; the evidence
files contain the complete processed rows. Row indices, source sample indices,
segment-local indices and event identities remain distinct.

Original bounded raw previews and raw summary fields, where present, are retained
inside the complete original analysis. A complete raw conductance series and
original input-byte bundle are excluded from this report profile. Do not describe
the package as either a complete raw-data export or containing no raw values.

Some unavailable original reports legitimately have no processed artifacts.
Current supported producers have zero or two artifacts; a lone artifact is
refused. Empty candidate rows within a valid artifact remain valid evidence.

## Architecture and history

The new renderer is `controlled-gaze-explicit-task-choice-eda-paired/0.1`, admission
`task-choice-eda-findings/0.1`, limits
`controlled-task-choice-eda-report-package/0.1` and selection
`brohn-report-package-selection/0.3`. Its execution plan pins all implementations
before queueing. Earlier profiles retain their original closed schemas.

EDA preparation is a distinct `eda_display` job/entity with adapter `eda-display`
and implementation `saved-eda-display/0.1`. Existing task display 0.2, choice
display 0.1 and explicit distribution 0.2 keep their existing contracts. The
distribution prerequisite continues to use `task-choice-findings/0.1`; adding EDA
to a report does not widen the questionnaire producer's source admission.

The intent retains normalized EDA window requests and a frozen required-source
snapshot. Required EDA parents are prepared even when only a paired figure is
selected. The same exact source selected directly and required indirectly is
prepared once. Related-only EDA receives complete numerical companions and no
automatic figures. Other nonselected parent types retain relationship proof;
this does not claim their complete numerical export.

The ordered source graph preserves full report identities and parent edges.
Selected report ordinals remain stable; related EDA follows in first-seen source
order. The bounded metadata binding is separate from the full provenance context
read behind the supervised worker boundary. Unknown required sources, cycles,
foreign references and changed provenance refuse instead of dropping evidence.

Queue/catalog work uses bounded metadata. Complete stream parsing, typed-value
validation, source verification, display reduction and export run under the
supervised worker. Native source guards remain held until the R worker and its
Python descendants stop. Publication rechecks original source authority and the
exact active lease before retaining any artifact.

One guarded renewal clock now spans source preparation, the child and verified
publication for this profile. Normal 60-second leases renew every 15 seconds;
expired, cancelled and replaced attempts still refuse. Resource deadlines and
native source/publication fences remain unchanged. Private table writers stay
open during indexing and close before reads, avoiding the observed Windows
append-open conflict with resource monitoring.

Exact decimal source-window membership does not use a floating-point round trip.
New typed display hashes distinguish null, empty arrays/objects, booleans and
signed zero. Scoped JSON transport preserves negative zero and refuses integer
tokens beyond exact binary64 integer transport. Original report/job/artifact
hash schemes remain unchanged. Historical downloads verify original producers
and current reader authority, without replacing old preparations with today's
implementation or rerunning science.

## Acceptance and continuation

Required gates separate original scientific source generation, independent
source/export conservation, typed transport, guarded worker/refusal behavior,
historical compatibility and actual researcher/browser/download/restart checks.
Synthetic and replay sources must retain those labels. Component assertions and
figure fixtures are not whole-application acceptance.

The published limits remain bounded profiles, not workload qualification:
eight selected reports, 32 source-closure reports and 100 actual figure/status
panels. Every selected candidate-marker page counts as a real panel. Complete
EDA streams have a separate 96 MiB/one-million-row budget, with a 192 MiB
complete-evidence projection budget; package output retains the existing 256 MiB
uncompressed limit. No output is silently truncated.

The actual 500,100-sample source can prepare a 101-sample figure window while
retaining all 666,734 original processed rows. Its complete-evidence projection
still exceeds 192 MiB, so it cannot produce a complete package under this profile.
The interface explains this single-source limit and prevents an unchanged retry
from being presented as a remedy. Its original saved-report exports remain
available separately. Larger complete exports need their own implementation
and qualification; shrinking or hiding figures cannot substitute for that work.

Before method-readiness sign-off, address the reproduced constant-input
continuous EDA detector counterexample with a versioned method policy and
independent witnesses. Follow [the versioned remedy plan](../methods/EDA-CONSTANT-SIGNAL-NEXT.md).
Original saved values remain unchanged; display their
saved flatline flags and do not confuse export conservation with detector
validity. The phase record separates actual cold-window editing, real large-source
refusal/recovery and the independent numerical preservation checks.

Next report family is the separately qualified [saved ECG/PPG extension](SAVED-CARDIAC-REPORT-NEXT.md). EEG and other
report families, raw bundles, stimulus image context, larger workloads, named
physical devices and hosted deployment evidence retain their own work. This
slice does not close any of Brohn's 50 capabilities or 17 build packages.
