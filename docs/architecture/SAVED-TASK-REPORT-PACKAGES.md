## Source and scientific boundary

The report presents existing results. It adds no scorer, task–liking estimator,
correlation, cross-task normalization, physical timing or construct-validity claim.
Liking/scales and compatible paired findings retain their own saved analyses.

| Supported task profile | Source evidence |
| --- | --- |
| IAT | Exact saved native or declared imported administration and its original scoring recipe. |
| BIAT | Exact abbreviated-task procedure, selected positions, exclusions and saved metrics. |
| AAT | Original task definition and saved response/approach metrics; no inferred physical movement. |
| Simple reaction time | Original schema/version, responses, missingness and latency support. |
| Choice reaction time | Original correctness, response/missingness and latency support. |
| Brohn response-window SC-IAT | Its named versioned procedure and saved window-specific metrics. |
| Brohn single-target GNAT | Deadline responses, genuine withholding, missing positions, cells and all ten metric records, including null unavailable metrics. |

Three strict source families are supported:

- `native_questionnaire`: complete questionnaire, scale, revision and task-score
  collections; packed previews hydrate from their original complete artifact.
  Source membership binds original protocol/journal receipts and scientific producer.
- `imported_implicit`: complete scores, canonical attempts, raw source rows,
  source-row hash, parameters, quality and limitations. Unselected other-task
  rows and their exact lexical cells remain present. Evidence is a declared
  trial summary, never a replayed native administration.
- `saved_task_cohort`: saved membership, attempt metrics, per-session/per-person
  records, summaries, contrasts, quality and provenance. Complete unlinked
  cohorts retain null person denominators and the saved linkage reason.

Required exact parents receive source-integrity and access checks. An unselected
parent is not silently added to the report's complete-export inventory. A native
source missing required original protocol/journal linkage is unavailable for this
profile and retains its existing export. Unknown or unsupported scientific
collections fail clearly rather than disappearing from a mixed report.

## Prepare once, then read saved evidence

One Prepare action first persists the request and an execution plan. That plan
pins the profile and preparation/renderer identities before prerequisites start.
Each selected task source requires a `task_display` artifact, even if its task
figures are hidden. Explicit distributions remain a separate prerequisite.
Shared dependency ownership and the existing cancellation/retry lifecycle apply.

The supervised task-display parent holds exact original sources and native run
snapshots. Its child validates the full original science and prepares a frozen
display audit/model. Native journal replay may occur here, under the pinned
preparation implementation. A display disposition rebuilt from registered rules
is identified as such; it is not relabelled as the original scoring audit.
No original score, importer or cohort reducer runs in this preparation path.

Assembly consumes complete unaliased reports plus the exact prepared evidence.
It validates source/model bindings before projecting identities and rendering.
Assembly, download and historical opening never replay native journals, rerun a
scorer or replace the saved preparation with current-head explorer output.

The new renderer is `controlled-gaze-explicit-task-paired/0.1`, with limits profile
`controlled-task-report-package/0.1` and selection schema
`brohn-report-package-selection/0.2`. Its `prepared_sources` records bind adapter,
source report, prepared reference and implementation reference. The original
selection schema/renderer keeps its `display_refs` contract unchanged.

`task_displays` in the pure bundle contains exact `{ref, body, evidence}` records.
The prepared `brohn-task-display-evidence/0.1` binds the original report and result
object, complete-analysis hash, preparation identity, administrations/cohort
models and coverage. Native evidence retains the complete terminal export;
import evidence retains complete declared summary/audit and mapped raw rows.
The package is not a byte archive of original journals or raw recordings.

## Metadata, selectors and history

Metadata callbacks use bounded catalogs; they do not hash/decode full sources,
launch Python or replay journals. Public task interfaces include:

```r
brohn_task_display_implementation()
brohn_task_display_implementation_ref()
brohn_queue_task_display(store, report_ref, retry = FALSE,
  implementation_ref = NULL)
brohn_task_display_catalog(store, display_ref, cursor = NULL, limit = 25L)
brohn_report_package_selector_catalog(store, report_ref, adapter,
  cursor = NULL, limit = 25L, prepared_ref = NULL)
```

Load-captured task identity names its declared algorithm/transport dependencies;
supervised execution checks those bytes again. It is not a claim to hash every
installed app file. The durable renderer plan separately pins shared dispatch
and renderer dependencies. Code drift requires an explicit new preparation;
passive reopening cannot silently update defaults or implementation.

Catalog rows carry exact administration/metric keys, compatible choices,
model hashes and row counts. All-applicable/profile-default request policies stay
unchanged while exact selections resolve asynchronously. Advanced controls use
prepared metadata when available; they do not invent choices from the first page
or a packed preview. Saved task, explicit and packed-paired selectors retain the
exact prepared reference through history and pagination. A missing required
historical reference stays unavailable instead of falling back to a newer one.

## Figures, complete evidence and refusal

`task-scores`, `task-trials` and `task-people` preserve the distinct saved source
families. Trial charts show profile positions and original response outcomes;
cohort figures respect original repeat weighting and availability. Profile-specific
latency defaults and compatible charts avoid treating all tasks as one D score.
Selected numerical pages are display alternatives, not export truncation.

Complete numerical projections include scores, original audits, typed trial/source
evidence and cohort collections even when only a subset of figures is selected.
Identifier projection preserves native score/evidence links, canonical versus
source attempt IDs, mapped raw CSV cells and cohort source/reviewed identity
relationships. Blank cells stay blank; absent, null, false and zero stay distinct.
Source-identifier mode retains original named identities. Free text is verbatim.

The actual profile maximum is 100 expanded figure panels and at most 100 request
sections. Bounded task/distribution metadata can reject a known excess before
selection freezes. For counts requiring complete gaze/paired models, the real
worker runs authoritative full-bundle preflight before output publication.
`panel_limit` produces a reviewable intent with the frozen selection and successful
preparation retained; no partial package is published. Reducing figures creates
a new intent and reuses compatible preparation while preserving complete data.
The actual 118-to-20 recovery has API/worker and independent full-output evidence.

## Authority, limits and remaining work

Native seals hold original source and prepared artifacts through supervised
publication. Current source, queued actor, intent generation and job lease/token
fences repeat before commit. Saved reads apply fresh current-reader and source
eligibility plus original successful-producer proof; expired original producer
credentials do not become today's reader credentials. These controls cannot
revoke already downloaded offline copies.

Task material definitions, hashes and retained reference closure are preserved.
Task PNG/JPEG/WebP image bytes and stimulus context panels are explicitly outside
this slice. The optional image checkbox applies only to existing qualified gaze
stimulus images. This does not change task collection materials or protocols.

The report runtime remains CPython 3.12.10 / Pillow 12.3.0 with the pinned R/native
profile. Larger workloads, raw/original-byte bundles, broader report families,
MaxDiff, post-collection restrictions and public hosting remain separate work.
Historical RT score schema 1.0 has a structural compatibility branch, but this
packet's genuine current producers emitted schema 1.1; an original retained
RT1.0 producer/worker witness is still required. Final mobile, connected, restart
and independent download evidence is recorded in the acceptance document. Narrow-screen figures use accessible
horizontal panning, not responsive re-layout or a qualified print layout.
