# EEG analysis implementation specification

Brohn draft, 2026-09-08; target **MNE-Python 1.12.1**. Reuse MNE for numerical extraction in an isolated local Python worker. R owns recipe selection, inclusion rules, contrasts, statistical interpretation and reports. This specification prepares standard analysis routes; it does not qualify every route for every headset, population or experiment. Scientific reporting follows the [SPR EEG/MEG guidelines](https://pubmed.ncbi.nlm.nih.gov/24147581/) and [frequency/time-frequency recommendations](https://pmc.ncbi.nlm.nih.gov/articles/PMC9717489/).

## Import and worker boundary

Select native readers explicitly: `mne.io.read_raw_edf`, `read_raw_bdf`, `read_raw_brainvision`, `read_raw_eeglab` or `read_raw_fif`. Preserve companion files and annotation channels. Unknown proprietary formats require a documented adapter. Check original sample count/rate, channel ordering/types, scaling, clipping and event mapping before processing. EEG arrays entering `RawArray` use volts; convert declared microvolts by `1e-6`, never infer units from magnitude. [EEG readers](https://mne.tools/stable/auto_tutorials/io/20_reading_eeg_data.html), [array conventions](https://mne.tools/stable/auto_tutorials/simulation/10_array_objs.html)

Use `set_channel_types` and `set_montage`; store original names, alias mapping, coordinate frame and measured-versus-template positions. Missing locations block topology-dependent operations, not every channel-level analysis. Record acquisition reference separately from `set_eeg_reference` choices. Average reference, named electrodes and bipolar derivations are distinct recipes; log applied projections, excluded reference channels and rank changes. [Montages](https://mne.tools/stable/auto_tutorials/intro/40_sensor_locations.html), [reference API](https://mne.tools/stable/auto_tutorials/preprocessing/55_setting_eeg_reference.html)

Worker requests contain allowlisted operation, immutable input hashes, study/session/protocol/event revisions, recipe revision and explicit parameters. Responses contain artifact hashes, array axes/units, QC, warnings and per-measure status. Preserve original sample indices, `first_samp`, recording origin and external-clock uncertainty. Return large arrays as bounded artifacts; keep small summaries in JSON. No arbitrary submitted Python, silent parameter substitution or live-device ownership in the analysis worker.

## Preprocessing and quality review

Produce raw traces, PSD, amplitude/flatline/clipping summaries, missing spans and event-count checks. Record bad channels in `info['bads']` and bad spans in `Annotations`; retain reasons and reviewer decisions. Separate detected defects, interpolation and exclusion. Interpolate only with adequate valid neighbours and known geometry; retain the original bad-channel list and resulting rank.

Use `Raw.filter`, `notch_filter` and `resample` with explicit design, cutoffs, transition widths, phase, padding and operation order. Treat disconnected spans separately. Notch only identified line frequencies/harmonics within the usable spectrum. Review filter response and edge exclusions; filtering can distort ERP shape. Resampling requires antialias filtering. Extract events at original resolution; preserve original events and record resampled mappings/jitter. Plain decimation is not an antialias filter. [Filtering/resampling](https://mne.tools/stable/auto_tutorials/preprocessing/30_filtering_resampling.html)

Fit `mne.preprocessing.ICA` with fixed seed, algorithm, rank-aware component count and convergence status. MNE recommends a separately high-pass-filtered fitting copy, commonly 1 Hz; this does not set the ERP analysis high-pass. Keep fitting/application channel and reference transforms compatible. `find_bads_eog`/`find_bads_ecg` produce candidates; review component maps, spectra, time courses and before/after traces before `ICA.apply`. Retain candidate scores, exclusions and reviewer record. Missing EOG/ECG channels must remain explicit; no invented reference signal. Optional automatic component classifiers need their own pinned dependency/model and reviewed operating conditions. [ICA workflow](https://mne.tools/stable/auto_tutorials/preprocessing/40_artifact_correction_ica.html)

## Epochs and evoked responses

Construct `mne.Epochs` with explicit event mapping, `tmin`, `tmax`, `baseline`, `reject`, `flat`, `reject_by_annotation`, picks and repeated-event policy. Baseline endpoints are inclusive; `baseline=None` disables correction. Rejection thresholds use channel-native SI units. Preserve `selection`, `drop_log`, trial metadata and original event IDs. Report requested, missing, rejected and retained trials per participant/condition/reason; empty or insufficient cells produce unavailable outputs. Baseline and artifact rejection order are recipe fields. [Epochs API](https://mne.tools/stable/generated/mne.Epochs.html)

Use `epochs[condition].average()` for participant-level ERPs. Output waveform in volts, display microvolts, retain `nave`, channel/time axes and SEM or appropriate uncertainty. Define electrode ROI, polarity and latency window before condition inspection. Mean amplitude is the mean over that declared interval/ROI; peak amplitude/latency (`Evoked.get_peak`) needs a declared polarity, search window and edge-peak handling. Fractional-area latency is a separate estimand. Never choose a peak on a grand average then claim an independently confirmed component effect. [ERP workflow](https://mne.tools/stable/auto_tutorials/evoked/30_eeg_erp.html)

## Spectral and time-frequency outputs

| Analysis | Explicit implementation and output |
|---|---|
| Welch PSD | `Raw/Epochs.compute_psd(method='welch')` or `psd_array_welch`: window, `n_per_seg`, `n_fft`, overlap, detrending/`remove_dc`, averaging, frequency range and accepted segments. Preserve channel/epoch/frequency axes. Zero-padding increases grid density, not underlying frequency resolution. [Welch API](https://mne.tools/stable/generated/mne.time_frequency.psd_array_welch.html) |
| Multitaper PSD | `psd_array_multitaper`: bandwidth, adaptive weighting, low-bias setting and **`normalization='full'`** for density scaling. The default `'length'` is different. Record usable duration and taper configuration. [Multitaper API](https://mne.tools/stable/generated/mne.time_frequency.psd_array_multitaper.html) |
| Band summaries | Density is V²/Hz; integrated band power is V², converted to µV² by `1e12`. Declare band boundaries, boundary-bin integration and rejected-frequency treatment. Relative power divides by an explicitly declared usable denominator band; zero denominator is unavailable. Power dB uses `10 log10(P/P_ref)` with the reference stated. Do not average dB and linear power interchangeably. [Spectral recommendations](https://pmc.ncbi.nlm.nih.gov/articles/PMC9717489/) |
| ERSP / ITC | `Epochs.compute_tfr(method='morlet'/'multitaper')`: frequencies, cycles, taper bandwidth, zero-mean setting, padding and decimation. Use `average=False` for trial power; a separate `average=True, return_itc=True` request returns averaged power and ITC. Declare total versus evoked-subtracted induced power. ITC is phase consistency across retained trials, bounded 0–1, with trial-count sensitivity. Wavelet power is not automatically PSD density. [TFR workflow](https://mne.tools/stable/auto_tutorials/time-freq/20_sensors_time_frequency.html) |

Define ERSP baseline and transform explicitly: difference, ratio, percent or `10 log10(P/P_baseline)`. Record whether normalization precedes or follows averaging; these differ. MNE's `logratio` requires an explicit factor of ten for dB. Reject zero/nonpositive denominators; exclude wavelet edge regions and require sufficient baseline support. [Baseline transforms](https://mne.tools/stable/generated/mne.baseline.rescale.html)

## Advanced analyses and comparisons

Connectivity is a separate optional package/recipe: `mne_connectivity.spectral_connectivity_epochs`, with channel/source pairs, frequency range, estimator and epoch duration/count fixed. Coherence/PLV can reflect common sources and reference effects. Imaginary coherency or debiased wPLI address particular mixing effects, not causal identification; source analyses require an independently qualified forward model. Do not install or expose connectivity as already qualified. [Connectivity API](https://mne.tools/mne-connectivity/stable/generated/mne_connectivity.spectral_connectivity_epochs.html), [Nolte et al.](https://pure.johnshopkins.edu/en/publications/identifying-true-brain-interaction-from-eeg-data-using-the-imagin-3/)

R performs participant-aware paired/group or hierarchical comparisons, retaining condition/order covariates and missing-cell decisions. Define the testing family and multiplicity correction. A worker may execute a specifically requested MNE permutation calculation, with exchangeability, adjacency, seed and permutations logged. Cluster significance does not identify exact onset, offset or location. [Cluster interpretation](https://pubmed.ncbi.nlm.nih.gov/30657176/)

## Presets, evidence and release gates

Presets populate editable, versioned settings; they never substitute a universal filter, alpha band, ERP window, minimum trial count or engagement score for a method rationale.

Reference ladder: deterministic sinusoids for PSD integral/units; offset epochs for baseline/ERP arithmetic; impulse/events for filtering and timing; seeded artifact mixtures for ICA behavior. Then use a permissioned external [EEGMMIDB reference run](https://physionet.org/content/eegmmidb/1.0.0/) for EDF/events and compare against its documented task structure. Real reference data stay outside the repository.

Graduation requires: independent numerical expectations; native-file/units/event agreement; reviewed artifact behavior; repeatability within declared tolerance; representative rig/participant evidence; and method-specific reliability/retained-data criteria. Log Python/MNE/dependency versions, all parameters/seeds, filter coefficients, reference/montage, source hashes, masks and review revisions. Analytic checks establish implementation behavior only; consult recorded benchmark results for actual completion status.
