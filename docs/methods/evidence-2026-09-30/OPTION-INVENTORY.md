## Study-template seam

`R/platform-core.R:58` exposes structural starters `comparison`, `survey`, `blank`. Comparison defaults are two Control/Test concepts, 5000 ms each, a seven-point liking question, counterbalanced order/seed 104729, baseline 0 ms and fixation 500 ms. They are editable starting values, not universally suitable research prescriptions. `R/platform-library.R:85` freezes/reuses a design with original revision/hash, but has no dedicated evidence-review field. The design audit in `study-design/` owns the deeper template/control/power/timing review.

## Citation findings

`brohn_task_profiles()` exposes a single `source` string per profile; most scientific recipes instead rely on prose docs, engine notes or free-text `settings_source`. This preserves provenance intent but does not link each option/default to a scholarly claim. The historical reuse README explicitly dates its claims to 8 September. The planning `EVIDENCE-COVERAGE.md` concerns vendor interface reference coverage; it is not an academic validity inventory. A file/code/test/source pointer must therefore have its own type and review status.
