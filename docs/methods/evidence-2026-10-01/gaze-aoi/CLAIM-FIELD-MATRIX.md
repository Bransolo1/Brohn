# Exact claim–field matrix

All paths below are relative to source16 `checkout`; line numbers bind the exact files in `BINDINGS.json`. `mapping` means the validated sampled-gaze `metadata` passed to `brohn_raw_gaze_analysis`, not a new schema. Source identifiers resolve in `SOURCES.md`. Proposed claims apply only to the named draft method. Imported prepared events and other gaze providers retain their own definitions.

| ID / family | Current fields and code locator | Actual implemented definition | Academic support, limit and action |
|---|---|---|---|
| G1a / detector | `mapping.geometry.{width_mm,height_mm,distance_mm,center_x_mm,center_y_mm}` and `mapping.geometry_source`; `R/platform-gaze.R:16–26,49–52` | Fixed planar rays from normalized coordinates; adjacent angular displacement uses `atan2(cross-norm,dot)`. Geometry is required input. | S4/S5: assess/report acquisition and geometry applicability. Do not inherit head-motion, VR, webcam or vendor-filter qualification. Geometry changes that alter the scientific transform require a named recipe. |
| G1b / detector | `mapping.parameters.{velocity_threshold_deg_s,min_fixation_ms,min_saccade_ms,max_gap_ms,threshold_source}`; `platform-gaze.R:45–48,138–178` | Low velocity is `<=` threshold; high is `>`; usable interval durations are summed. Short runs become `short_unclassified_segment`.
