## Validation

773 counted R checks at 01L, plus report/JSON/Shiny workflows: valid drafts, serialization, wrong schema,
missing ID, invalid revision, unsupported design, duplicate stimuli/measures,
unknown measures, mismatched question selection, duplicate options, malformed
codes, reversed contrast, false qualification, four origin modes, invalid mode,
and registry maturity, plus event identity conflicts, declared segment/source resets,
clock provenance, raw timestamp syntax/precision, stale revisions, rating/option
coherence, missingness, response phase, unknown/duplicate fields and JSON shape.
JavaScript verifies wire semantics and re-encodes the bundle; R decodes and compares
it with the original. Native Windows R 4.6.1 / jsonlite 2.0.0 checks now also cover
failed replacement, stale fingerprints, locking, UTF-8 and draft revisions. Shiny
1.14.0 / bslib 0.12.0 server checks cover editing and recovery. Browser navigation
and reopening were verified. Prepared arithmetic, control roles, sequence previews,
CSV import/save/reopen and downloaded report reproduction pass. Production packaging,
device references, scientific qualification and formative testing remain open.
