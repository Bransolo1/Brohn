# Open research platform: strategic design package

Version 0.2 · 5 September 2026

Extract the ZIP and open **START-HERE.html**. Keep the folders together. The dossier, sequence figures and screenshot gallery work locally; external source links require internet access. Markdown files are editable sources and HTML files are reading copies.

## Start with

- **REVIEW-AND-CHANGES**: the two-team audit, 44 findings, revised behavior and delivery implications.
- **ARCHITECTURE-CONTRACT**: researcher interface, R services, study compiler, participant execution, hardware capture, durable processing and report state; three static sequence figures and source diagrams.
- **STRATEGY**, **UX-AND-ROADMAP** and **R-ARCHITECTURE**: product direction, first 12 provisional sprints, staged expansion, packages and qualification gates.
- **QUESTIONNAIRE-BUILDER** and **WEBCAM-EMOTION-ATTENTION**: full specialist scopes and requirements.
- **UX-TEAM-REVIEW**, **BIOVITAL-TEAM-REVIEW**, **IMPLICIT-METHODS-REVIEW**: detailed findings and proposed fixes.
- **GAP-REGISTER.csv/json**: each finding mapped to evidence and delivery tickets.
- **IMPLEMENTATION-BACKLOG.csv**:238 candidate items; eight net new after deduplicating the audit proposals. Includes review references, acceptance criteria and dependencies.
- **BACKLOG-REVISION-MAP.json**: traceable changes to existing tickets and new ticket additions.
- **UI-ATLAS.html**:150 distinct still references across 16 platforms, including 34 added for this review. Search workflow terms or a gap ID; filter the review collection.
- **EVIDENCE-COVERAGE**, **VIDEO-WORKFLOWS** and **COMPETITOR-REVIEW**: source limits, remaining observation needs and nine timestamped tutorial stills.
- **evidence/manifest.csv/json**: portable image paths, sources, versions where known, dimensions and SHA-256 hashes.
- **PACKAGE-VERIFICATION.json**: deliverable validation results.

This package specifies an original, R-first research platform. It does not contain an implemented or scientifically validated application. The in-conversation concept uses simulated values and demonstrates selected interaction changes. No GitHub repository has been published.

## First delivery objective

An undergraduate runs the prepared “Compare two visual designs + liking” sample, receives a reproducible analysis and explains it within 10 minutes and at most 5 total interface activations. These are acceptance targets, not measured usability results. The broader platform connects eye tracking, EEG, EDA, physical push/pull, named BIAT/RT tasks, questionnaires and qualified webcam methods through the same study model.

## Reference collection

Public documentation screenshots, manual excerpts, feature illustrations and paused tutorial stills inform the design. A screenshot does not prove an entire current workflow, scientific validity or feature absence. No MP 4, WebM, MOV, AVI, MKV or animated GIF is included.

Keep third-party reference imagery separate from the future publicly licensed code. The open repository should contain original interface assets, permitted fixtures and source links. The code licence does not automatically license vendor screenshots.

## Verification scope

Package checks cover local links, image hashes, evidence/gap IDs, unique tickets and an acyclic dependency graph. Representative reading layouts, source stills and atlas filtering/enlargement were inspected. The revised concept was exercised for clean sample navigation, design invalidation, liking removal, AOI flag/accept/undo and the required-review recovery route. These are checks of deliverables and an illustrative concept; hardware, numerical methods, security and undergraduate usability require later validation.
