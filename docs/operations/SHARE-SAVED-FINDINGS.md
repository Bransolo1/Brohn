# Prepare and share saved findings

Brohn can assemble supported saved gaze, questionnaire and paired findings into an offline report with complete numerical companions. Report preparation uses the saved calculations; it does not run another scientific analysis.

## Prepare a report

1. Open the saved findings you want to share and choose **Prepare report**. A compatible combined report offers its exact linked gaze and questionnaire reports, so you can review them together. You can also enter from the study's **Results** and choose saved findings.
2. Give the report a title. **Change contents** lets you include or remove exact saved reports, order figure sections, choose particular saved views or figure pages, and decide whether to include stimulus images or original participant/session identifiers.
3. Choose **Prepare report**. Brohn saves your choices first, prepares response distributions if needed, then assembles the report. Existing distributions are reused when they match the exact selected report.
4. When the report is ready, choose **Download report** for its standalone HTML, or **Download report + evidence** for the ZIP.

The initial profile supports complete compatible gaze, questionnaire and paired findings. Known unsupported report families or embedded collections explain why their package adapter is unavailable; their existing reports and exports remain available. A package does not silently drop an unsupported scientific collection.

## Read the download

The HTML opens without an internet connection. It includes the selected figures, their numerical alternatives, methods, coverage and limitations. Friendly person/visit labels are shown within their source context. Displayed summaries use readable precision; the evidence retains the saved numerical values.

The ZIP includes that same HTML, an inventory with checksums, selected SVG figures, complete supported numerical JSON and CSV collections, source references and saved method information. Unpack the ZIP before following the HTML's evidence links. Changing figure pages does not trim those complete collections.

Excluding stimulus images leaves a labelled geometry frame and preserves the numerical evidence. Including images requires verified, supported PNG/JPEG bytes and matching saved geometry. Unsupported orientation or image bounds produce an explanation; Brohn does not guess an AOI transform. This profile excludes raw recordings and original byte-evidence bundles.

Package-local labels preserve the saved relationships between people, visits and source reports. They do not make the report anonymous: free-text answers remain verbatim. Offline copies cannot be revoked by later changes in Brohn.

## Revise, cancel and return later

Preparing changed title, contents or display choices creates another saved preparation. Editing alone marks the draft changed and invalidates the previous download links. The earlier successful report remains in **Saved report packages**. Select **Open saved report** to reopen its exact contents without rerunning the science.

Use **Cancel preparation** to stop unwanted preparation. **Retry preparation** is an explicit action; it preserves an already frozen selection and obtains current authorization. Leaving this page or closing the session does not cancel already queued work; reopen **Saved report packages** to inspect it. An unfinished next step requires explicit **Resume preparation**. Shared display work is retained when another active preparation still needs it.

Brohn checks current access and source availability when opening a saved package or using its download links. A changed form invalidates the links for the previously opened choices. Reopen the saved version to obtain fresh links. These checks protect access inside Brohn; they do not change already downloaded copies.

## Scope

The report presents existing findings and their saved support. It does not establish device accuracy, construct validity, attention or emotion merely by visualizing measurements. Other report families, larger workload profiles and the platform-wide post-collection restriction ledger remain separate work.
