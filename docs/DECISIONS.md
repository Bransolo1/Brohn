## Foundation decisions retained

- 2026-09-05: R-first, with pure R domain/science code. Begin dependency-free.
- Sprint 01B adds jsonlite for the draft JSON boundary, tested at 2.0.0. Raw
  timestamps use decimal strings to preserve precision across R and JavaScript;
  revisions/sequences stay within their shared exact integer range.
- Clock/stream/event and response records precede recording and durable storage.
  Bundle validation preserves internal origin consistency, not tamper resistance.
- Researcher UI uses Shiny/bslib; the initial guided draft shell is implemented.
- Participant timing and hardware recording run independently from Shiny.
- Persist raw recordings separately from derived data; later jobs use frozen
  inputs and produce traceable reports. Local draft JSON storage is implemented;
  raw recording/derived-artifact storage remains future work.
- Draft titles are optional in contract 0.1.0 for backward compatibility with the
  earlier local fixtures. New drafts include a title; stable identity is separate.
- Desktop save uses a same-folder rename and a cooperating-writer lock; it never
  deletes the original as a fallback. Power-loss/network-filesystem guarantees
  require a later storage design. Fingerprints prevent app-to-app stale writes.
- Local development first; shared/cloud deployment and device adapters later.
- Copy existing planning prose once. STATUS.md is the concise resumption point.
- Research gates stay open until measured. A passing synthetic check is not
  scientific, device or usability qualification.
- Packaging, source licence, renv lock and dependency inventory precede public
  release. No remote destination or publisher identity has been supplied.
- Control/test role is distinct from stimulus identity and order. Optional draft
  comparison/presentation fields preserve old 0.1.0 drafts. AB/BA plans do not
  assert achieved assignment or observed delivery; five seconds is an editable preset.
- Begin analysis with an explicitly unqualified prepared-interval kernel and
  independently calculated fixtures. Keep fixed fictional sample data separate
  from imported prepared data and from raw device preprocessing.
- Canonical CSV import has an R/CLI path and a bounded local single-user UI.
  Portable reports retain original bytes, hash and frozen study; export/reopen
  recomputes results. Add isolated jobs and access control before shared uploads.
- 2026-09-08: Preserve the R/Shiny/browser/sidecar boundaries for the larger build.
  Adopt the six reviewed waves in ROADMAP.md, with questionnaire linkage, recovery,
  accessibility and undergraduate evaluation early in the complete eye journey.
- Exact R lock/restore and pinned JS development dependencies precede further
  integration. renv remains explicitly invoked; current launcher behavior stays.
- jsPsych is installed as a development candidate with synthetic execution checks,
  not yet a participant runner. Browser timestamps require physical qualification
  for timing claims. Quarto is a local HTML rendering tool, not a finished report recipe.
- 2026-09-08: Reuse established R/Python scientific libraries through explicit
  versioned recipes. R remains authoritative for method eligibility, quality,
  contrasts and reports; isolated workers may execute MNE/NeuroKit numerical APIs.
  This extends the initial pure-R kernel approach without changing timing or
  acquisition ownership. No worker service is activated by the reference scripts.
- Preserve published method support; Brohn adoption checks target units, settings,
  linkage and reference agreement. Additional interpretation/device/task changes
  require evidence for that extension, not an automatic repeat of original science.
- Effective parameters, quality masks, missing reasons, denominators, environment
  and raw/protocol hashes belong in immutable job/result manifests. Do not trust
  undocumented defaults or claim ignored wrapper options were applied. Specific
  findings and integration priorities: methods/reuse/README.md.
